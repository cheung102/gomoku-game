# 五子棋游戏

一个功能丰富的五子棋游戏，使用 Python + Pygame 实现。

## 功能特性

- 15x15 标准棋盘
- 双人对战模式
- 人机对战模式（简单/中等/困难）
- AI 对手（Minimax + Alpha-Beta 剪枝）
- 悔棋功能
- 游戏提示
- 获胜连线高亮
- 最后落子标记
- 鼠标悬停预览
- 胜负统计
- 游戏计时
- 音效反馈
- 中文界面

## 运行

### 控制台版本
```bash
python game.py
```

### 图形界面版本
```bash
python gui_game.py
```

## 操作说明

| 操作 | 快捷键 |
|------|--------|
| 悔棋 | Z |
| 提示 | H |
| 重新开始 | R |
| 返回菜单 | Esc |

## AI 难度

| 难度 | 说明 |
|------|------|
| 简单 | 随机落子 + 基础阻挡 |
| 中等 | 评分系统选择最佳位置 |
| 困难 | Minimax + Alpha-Beta 剪枝算法 |

## 游戏规则

1. 黑棋先手
2. 轮流落子
3. 先形成五子连珠者获胜
4. 棋盘满为平局
